# DeepSeek-V4.1-Flash — 4× RTX PRO 6000 (96 GB), TP4: баланс экспертов для UVA-выгрузки

> [English](README.md) | **Русский** | [中文](README.zh.md)

**Статус: инженерный расчёт баланса + инструменты, не проверенный запуск обслуживания.**
Реальное и проверенное здесь — *баланс экспертов*: какие маршрутизируемые эксперты держать
в памяти GPU, а какие в закреплённой памяти хоста, и бюджеты байт на rank — посчитанные тем же
протестированным планировщиком, что и в эталонном рецепте MiMo. Серверная часть (лаунчер,
патчи модели) следует контракту эталона, но на целевом железе не запускалась.

Целевой хост: 4× RTX PRO 6000 Blackwell Workstation Edition — по 96 GB GDDR7 с ECC.
Карты PCIe Gen 5, но слоты хоста — **PCIe 4.0**, линия GPU↔хост ~25 ГБ/с на GPU;
RAM хоста — DDR4. Без NVLink.

| `scripts/manage.sh` | повседневное управление: status / logs / start / stop / restart / update / rollback / check |

| Hot-бюджет | 52 GiB/rank (лестница 47 / 52 / 57) |
| Якорь hot | 295 из 384 экспертов |

## Баланс
`balance.json` хранит геометрию; `patches/hotsplit_plan.py` (numpy, покрыт тестами) считает
жадный горячий набор по доле маршрутизации на байт. Проверки: NaN/отрицательные/несовпадающие
счётчики — ошибка, переполнение бюджета — ошибка, оракул подтверждает оптимальность.

## Запуск
```bash
bash scripts/preflight-tp4.sh
bash scripts/balance.sh                 # по вашей гистограмме трафика
MODEL_DIR=/models/DeepSeek-V4.1-Flash HOTSPLIT_DYNAMIC=1 scripts/run-tp4-uva.sh
```
Hot-бюджет задаётся через `HOTSPLIT_HOT_GIB` (per-rank). Все ручки — в `tp4.env.example`.

## Проверка
`scripts/check-hotsplit-tp4.sh <container> <dynamic|static>` — каждый rank должен отчитаться
`dynamic_hook=ACTIVE` (dynamic) и `hotsplit done`. Затем smoke-тест `/v1/chat/completions`.

## Известные ограничения
- Серверная часть не запускалась на целевом железе; проверьте Marlin MXFP4 с TP4-шардами.
- Ранжирование `expert_hist_mix.json` — эталонное; переранжируйте под свой трафик.
- EP не поддерживается. Спекулятивное декодирование не тестировалось.

## Откат
`scripts/rollback.sh` (останавливает+удаляет контейнер; `--start-baseline` запускает стоковый UVA).
