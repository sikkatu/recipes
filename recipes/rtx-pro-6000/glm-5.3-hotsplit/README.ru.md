# GLM-5.3 — 4× RTX PRO 6000 (96 GB), TP4: баланс экспертов для UVA-выгрузки

> [English](README.md) | **Русский** | [中文](README.zh.md)

**Статус: инженерный расчёт баланса + инструменты, не проверенный запуск обслуживания.**
Реальное здесь — *баланс экспертов*, посчитанный тем же протестированным планировщиком,
что и в эталонном рецепте MiMo. Серверная часть следует контракту эталона, но не запускалась
на целевом железе.

Целевой хост: 4× RTX PRO 6000 (96 GB GDDR7 с ECC). Карты PCIe Gen 5, слоты хоста —
**PCIe 4.0** (~25 ГБ/с на GPU); RAM — DDR4. Без NVLink.

| `scripts/manage.sh` | повседневное управление: status / logs / start / stop / restart / update / rollback / check |

## Геометрия и баланс
| Параметр | Значение |
|---|---|
| Слоёв | 75 |
| Маршрутизируемых экспертов | 256 |
| Top-k | 8 |
| Размер эксперта | 20.25 MiB |
| **Горячий банк (память GPU)** | **~36 GiB** (≈7282 ячейки, 38%) — якорь по измеренному кэшу на 7360 слотов |
| Холодный банк (закреплённый хост) | 58.92 GiB/rank, 235.7 GiB на 4 rank |
| Трафик декодирования | top-8 × 5.06 ≈ **40.5 MiB/токен/rank** |

Банк почти заполняет карту: hot 36 GiB оставляет VRAM под KV cache.

## Запуск
```bash
bash scripts/preflight-tp4.sh
bash scripts/balance.sh
MODEL_DIR=/models/GLM-5.3 HOTSPLIT_DYNAMIC=1 scripts/run-tp4-uva.sh
```

## Проверка
`scripts/check-hotsplit-tp4.sh <container> <dynamic|static>` — каждый rank: `dynamic_hook=ACTIVE`
и `hotsplit done`. Затем smoke-тест `/v1/chat/completions`.

## Известные ограничения
- Якорь — бюджет байт от измеренного кэша; *набор* должен прийти из вашей гистограммы трафика.
- 4 воркера закрепляют ~235.7 GiB RAM; держите запас хоста щедрым (128 GiB).
- MTP(2) спекуляция не тестировалась с любым hot/cold разбиением на этом железе.
- Серверная часть не запускалась на целевом железе.

## Откат
`scripts/rollback.sh` (`--start-baseline` — стоковый UVA).
